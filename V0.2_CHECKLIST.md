# HybridRenderer v0.2 Release Checklist

The v0.2 scope is the Hybrid path's RT shadow/AO, reflection, and diffuse-GI
signals with history-correct SVGF denoising. This checklist records the v0.2.0
release evidence and its boundaries. GPU validation, visual quality,
and portability are separate claims.

## Functional and history gates

- [x] The Hybrid graph has signal producers and supports SVGF off,
      spatial-only, temporal-only, and temporal-plus-spatial topologies. The
      fixed Box GPU smoke checks graph outputs and captures each mode.
- [x] First-frame SVGF temporal sampling rejects missing history rather than
      treating a valid fallback descriptor as valid previous-frame evidence.
- [x] The SVGF toggle smoke invalidates all six signal/moment histories,
      captures the reset frame, and captures recovery after 32 warm-up frames.
      It also cuts the camera with `Frame Scene`, verifies invalidation, and
      captures the first and recovered frames. This is evidence for explicit
      invalidation and camera cuts on one GPU, not every source of a reset.
- [x] The TAA GPU smoke checks resize, render-path switch, scene replacement,
      camera cut, and recovery. These checks do not substitute for SVGF tests.
- [x] A second smoke uses the bundled `TextureCoordinateTest.glb`. It frames
      and lights the front-facing card, captures all three paths, and rejects
      captures that lose the four expected colored quadrants. This checks
      static texture visibility, not material accuracy or denoising quality.
- [x] Exercise SVGF history through swapchain resize. The Hybrid toggle smoke
      captures the first 1280x720 frame and a frame after 32 warm-up frames,
      then restores 1600x900 before the Ray Traced resize check. On the local
      GPU, the first Box face is visibly noisy and the recovered face is
      smooth; the Refl temporal pass logs unavailable previous-frame history.
      This is a fixed-scene, single-GPU observation, not a quality guarantee.
- [x] Exercise SVGF history through scene replacement. The Hybrid toggle
      smoke clears the active scene, reloads the Box, verifies that model
      integration requested a fresh graph before rendering, and captures the
      first non-empty frame plus recovery after 32 warm-up frames. The local
      first frame is visibly noisy, the recovered frame is smooth, and the
      Refl temporal pass logs unavailable previous-frame history. Reloading
      the same Box tests scene identity/lifetime, not appearance changes.
- [x] Capture a two-object Hybrid fixture (bundled Box plus texture card) in
      still and moving states. The smoke saves final, shadow, AO, reflection,
      and GI display modes, plus camera, flags, GPU, raw driver version,
      resolution, and entity transforms in `result.txt`. On the local GPU,
      shadows move with the Box, AO has subtle contact variation, and GI and
      reflection outputs are non-black. These debug views prove signal paths
      execute; they do not establish physical accuracy or freedom from
      temporal artifacts at other speeds and scenes.
- [x] Establish a paired SVGF-on/off quality comparison on the two-object
      fixture. The local Release run reduced the Box red-face residual from
      64.55 to 0.20 and preserved a reflection-floor mean color within 20
      RGB8 levels per channel. It exposed and fixed receiver-albedo tinting
      of reflection/GI radiance. Amplified difference, still/moving final,
      reflection, shadow, AO, and GI images were inspected: texture labels
      remain legible and no large trail is obvious at the tested speed.
      Reflection edges are soft; one speed and one static screenshot cannot
      exclude subtle ghosting or establish physical accuracy.

## Engineering and release gates

- [x] Re-run Debug and Release builds, all eight CTest targets in each
      configuration, and `spirv-val --target-env vulkan1.3
      --scalar-block-layout` on all 25 generated SPIR-V modules. On the local
      RTX 5070 Ti, six GPU smoke modes passed in both configurations with
      `VK_VALIDATION_VALIDATE_SYNC=true` and no reported validation messages.
      These runs cover the local candidate source; they do not replace CI or
      other-GPU validation.
- [x] Review performance with a fixed Box scene and settings. The paired
      Release benchmark captures 60 warm-up and 180 measured GPU timestamp
      samples per profile at 1600x900 on the local RTX 5070 Ti. Full-effect
      SVGF passes total about 0.513 ms in average reported pass duration;
      with effect flags off, the three RT producer passes still run and report
      about 0.103 ms combined average. These pass sums are a diagnostic, not
      whole-frame latency or a portable speedup claim. The residual RT work
      is a future graph-pruning opportunity, not a v0.2 correctness blocker.
- [x] Update README status, known limitations, and changelog with measured
      evidence. Untested GPUs and feature combinations remain explicitly
      outside the validated scope.
- [x] Windows CI run
      [#9](https://github.com/CadenXc/HybridRenderer/actions/runs/36382337557)
      passed on the GPU-validated source candidate `2d684ad` (VS2022 Release
      build and eight CTest executables). The user explicitly approved the
      v0.2.0 tag and GitHub Release. The release-documentation commit is
      documentation-only and receives its own CI run before tagging.

## Current evidence boundary

The local GPU used for the current smoke runs is an NVIDIA GeForce RTX 5070 Ti
(raw Vulkan `driverVersion=2559508480`) at 1600x900. The quality fixture
adds a glossy texture card to the Box. Its four-neighbour red-channel
residual is measured only on one flat Box face; the reflection-color check
samples only one interior floor region. A successful smoke proves the tested
frame sequence executed without reported validation errors; it does not prove
temporal stability during arbitrary motion or correctness on other GPU
families. The v0.2.0 release does not claim complete rendering correctness or
support for untested hardware.
